# Vrushabh Dave - Resume

A professional resume website hosted on GitHub Pages.

## 🌐 Live Demo

Once deployed, your resume will be available at: `https://vrushabh59.github.io/Vrushabh-resume/`

## ✨ Features

- Clean and professional design
- Responsive layout (works on mobile, tablet, and desktop)
- Print-friendly styling
- Easy to customize
- Hosted for free on GitHub Pages

## 🚀 Quick Start

### Step 1: Customize Your Resume

Edit the `index.html` file to add your personal details:

1. **Header Section**: Update your name, title, email, GitHub, LinkedIn, and location
2. **Professional Summary**: Write a brief introduction about yourself
3. **Technical Skills**: List your programming languages, frameworks, and tools
4. **Professional Experience**: Add your work experience with job titles, companies, and responsibilities
5. **Projects**: Showcase your best projects with descriptions and technologies used
6. **Education**: Add your educational background
7. **Certifications**: List relevant certifications
8. **Achievements**: Highlight your accomplishments

### Step 2: Enable GitHub Pages

1. Go to your repository settings
2. Navigate to **Pages** section (under Code and automation)
3. Under **Source**, select "GitHub Actions"
4. The workflow will automatically deploy your resume

### Step 3: Deploy

Once you push changes to the `main` branch, the GitHub Actions workflow will automatically:
- Build your resume
- Deploy it to GitHub Pages
- Make it available at your GitHub Pages URL

## 📝 Customization Tips

### Change Colors

The resume uses a purple gradient theme. To change colors, edit the CSS in `index.html`:

```css
/* Find this line in the CSS */
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);

/* Replace with your preferred colors */
background: linear-gradient(135deg, #your-color1 0%, #your-color2 100%);
```

### Add More Sections

You can add more sections by following the existing HTML structure:

```html
<section class="your-section">
    <h2>Section Title</h2>
    <p>Section content...</p>
</section>
```

### Modify Layout

The resume is mobile-responsive. Media queries are included for different screen sizes.

## 🛠️ Local Development

To preview your resume locally:

1. Clone this repository
2. Open `index.html` in your web browser
3. Make changes and refresh to see updates
